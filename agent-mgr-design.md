# 智能体管理模块设计

## 定位

智能体管理 = **管理 AI 财税团队的"配置 + 状态"中心**。对应云升的"能力中心"和"智能体配置"两个页面合并而来。

它要回答 3 个问题：
1. **有哪些智能体**？（清单）
2. **每个智能体的状态和配置**（在线/离线、用了什么模型/能力/知识）
3. **怎么调整它们**（添加新智能体、修改配置、暂停）

## 设计：4 区


## 完整布局
```
┌────────────────────────────────────────────────────────────┐
│ 区 1：顶部总览（1 长卡）                                      │
├────────────────────────────────────────────────────────────┤
│ 区 2：智能体清单（3 大卡纵向堆叠）                            │
├────────────────────────────────────────────────────────────┤
│ 区 3：系统能力配置（MCP/模型/知识库分组）                      │
├────────────────────────────────────────────────────────────┤
│ 区 4：最近变更                                                  │
└────────────────────────────────────────────────────────────┘
```

## 视觉规范
- **区 1**：复用数据看板的 `.dash-kpi-strip` 样式
- **区 2**：每张大卡使用 `.dash-card` 样式，左侧色块表示智能体类型（智能体驾驶舱=蓝、开票=绿、风险=红）
- **区 3**：4 列 grid，每列一个能力组
- **区 4**：与"待我确认"类似的列表，但右侧是变更类型徽章

## 交互
1. **顶部 [＋ 创建新智能体]** → 弹 modal（4 步配置向导）
2. **智能体卡 [编辑配置]** → 跳到该智能体的专属配置页（或弹 modal）
3. **智能体卡 [暂停]** → 弹确认 dialog
4. **能力组 [配置/管理]** → 跳到对应配置页

## 实现优先级
- MVP：区 1 + 区 2（3 大卡精简版）
- 后续：区 3 + 区 4 + 编辑 modal
